## 📲 طريقة التثبيت

1. حمّل ملف APK من الرابط أعلاه.
2. افتح الملف ووافق على «التثبيت من مصادر غير معروفة» إذا طُلب منك.
3. للتحديث إلى نسخة جديدة: حمّلها وثبّتها فوق النسخة القديمة — بياناتك وإعداداتك محفوظة.
