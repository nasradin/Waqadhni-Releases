## ✨ مميزات التطبيق

- تذكيرات للمواعيد والأدوية والأفلام والمسلسلات والأخبار، مع تصنيفات خاصة تضيفها بنفسك

- تنبيه مبكر قبل الموعد (قبل 10 دقائق أو ساعة أو يوم)، وتأجيل سريع من الإشعار نفسه
- إرفاق صورة أو ملف PDF أو تسجيل صوتي مع أي تذكير
- الإضافة الذكية: تذكير كامل من جملة عربية واحدة
- التذكير بالموقع: إشعار يصلك عند وصولك إلى مكان محفوظ على الخريطة
- ودجت على الشاشة الرئيسية يعرض أقرب موعد وعدد الأيام المتبقية له
- عرض بالقائمة أو بالتقويم الشهري، مع إحصائيات وسجل لنشاطك
